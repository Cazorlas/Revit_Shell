## PaperEngineer Shell v1.4.0

PaperEngineer Shell now tells you when a new version is out and can install it for you.

### New

- **Check for updates** in the right-click menu. It checks GitHub Releases right away.
- **Automatic check.** After you use Revit Version Info or Open with exact Revit version, PaperEngineer Shell checks in the background, at most once every 24 hours.
- **Update prompt** with three choices:
  - `Update now`: downloads the MSI, checks its SHA-256 against the digest GitHub publishes, then runs the installer.
  - `Skip this version`: the automatic check stops offering this version. A newer version, or a manual check, offers it again.
  - `Later`: asks again on the next automatic check.

### Notes

- Windows asks for administrator rights while the update installs, and may ask to close File Explorer.
- This is the first version with the updater, so install 1.4.0 by hand. Later versions can then be installed from the prompt.
- The add-in is unsigned. When Revit shows the security prompt, choose `Always Load`; `Load Once` asks again on every start.

### Installation

1. Download `PaperEngineerShell_1.4.0.msi`.
2. Close all Windows Explorer windows and Revit.
3. Run the installer as administrator. It replaces any earlier Revit Shell or PaperEngineer Shell version.
4. Right-click a supported Revit file to access the PaperEngineer Shell commands.

### Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Internet access to github.com for update checks
- Autodesk Revit installed for the versions you want to open (Detach and Create new local: Revit 2014–2027)
