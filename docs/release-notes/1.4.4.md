## PaperEngineer Shell v1.4.4

Updating no longer closes File Explorer.

### Fixed

- Updating could leave Windows with no taskbar or desktop until a restart. Windows Installer closed File Explorer to replace the shell extension, could not start it again, and left an Explorer process running without the taskbar, so the 1.4.3 check ("is Explorer running?") did not notice. The installer now leaves File Explorer alone: it replaces the extension while Explorer keeps running, and the new version is used after you sign out, restart File Explorer, or restart Windows.

### Notes

- The fix is in the 1.4.4 installer itself, so it already applies to the update from 1.4.3 to 1.4.4.
- If the taskbar ever disappears after an earlier update, press `Ctrl+Shift+Esc`, find `Windows Explorer` in the Processes list, and choose `Restart`. Starting `explorer` from `Run new task` only opens a folder window while the old Explorer process is still running.
- Windows asks for administrator rights while the update installs.
- The add-in is unsigned. When Revit shows the security prompt, choose `Always Load`; `Load Once` asks again on every start.

### Installation

1. From 1.4.0 or later: accept the update prompt, or choose `Check for updates` in the right-click menu.
2. From an earlier version: download `PaperEngineerShell_1.4.4.msi`, close Revit, and run the installer as administrator. It replaces any earlier Revit Shell or PaperEngineer Shell version.
3. Right-click a supported Revit file to access the PaperEngineer Shell commands.

### Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Internet access to github.com for update checks
- Autodesk Revit installed for the versions you want to open (Detach and Create new local: Revit 2014–2027)
