## PaperEngineer Shell v1.4.3

File Explorer comes back by itself after an update.

### Fixed

- Updating from the prompt could leave File Explorer closed (no taskbar or desktop) until it was started by hand. Windows Installer has to close Explorer to replace the shell extension, and Windows did not always restart it. After `Update now`, PaperEngineer Shell now waits for the installer to finish and starts File Explorer again if it is not running.

### Notes

- The fix runs during updates made by 1.4.3 and later. The update from 1.4.2 to 1.4.3 itself still uses the old step, so if File Explorer does not come back, press `Ctrl+Shift+Esc`, choose `Run new task`, type `explorer` and press Enter.
- Windows asks for administrator rights while the update installs.
- The add-in is unsigned. When Revit shows the security prompt, choose `Always Load`; `Load Once` asks again on every start.

### Installation

1. From 1.4.0 or later: accept the update prompt, or choose `Check for updates` in the right-click menu.
2. From an earlier version: download `PaperEngineerShell_1.4.3.msi`, close all Windows Explorer windows and Revit, and run the installer as administrator. It replaces any earlier Revit Shell or PaperEngineer Shell version.
3. Right-click a supported Revit file to access the PaperEngineer Shell commands.

### Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Internet access to github.com for update checks
- Autodesk Revit installed for the versions you want to open (Detach and Create new local: Revit 2014–2027)
