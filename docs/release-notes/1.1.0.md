## Revit Shell v1.1.0

Opens workshared (central and local) Revit models the way you choose, straight from Windows Explorer.

### New

- **Open workshared models your way.** For a central or local model, `Open with exact Revit version` now asks:
  - `Detach from central` (keeps worksets; Revit names the copy `<model>_detached.rvt`)
  - `Create new local` (central models only; saves `Documents\<model>_<Revit username>.rvt` and renames an existing one to `_backup_<yyyyMMdd-HHmmss>`)
  - `Open directly`
  - `Cancel`
- **Worksharing in Revit Version Info.** Shows whether a file is Central, Local or not workshared, and the central model path.
- **Revit Shell Open Helper add-in.** Installed for Revit 2021–2027; it carries out Detach and Create new local inside Revit and does nothing in normal Revit sessions.

### Improved

- Selecting several files no longer stops at the first failure: the other files still open and all problems are listed together.

### Notes

- The add-in is unsigned. When Revit shows the security prompt, choose `Always Load`; `Load Once` asks again on every start.
- Revit 2027 support is built against the Revit 2027 API but has not yet been tested on a Revit 2027 installation.

### Installation

1. Download `RevitShell_1.1.0.msi`.
2. Close all Windows Explorer windows and Revit.
3. Run the installer as administrator. It upgrades an existing 1.0.0 installation.
4. Right-click a supported Revit file to access Revit Shell commands.

### Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Autodesk Revit installed for the versions you want to open (Detach and Create new local: Revit 2021–2027)
