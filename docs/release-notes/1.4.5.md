## PaperEngineer Shell v1.4.5

The update prompt now offers only `Update now` and `Later`, and says when File Explorer needs a restart.

### Fixed

- After an update, File Explorer keeps running the old version until it restarts. The old version kept offering the update it had just installed, and `Update now` ran the same installer again with nothing visible happening. PaperEngineer Shell now compares releases with the version installed on disk. When that version is newer than the one running, the automatic check stays quiet, and `Check for updates` says to restart File Explorer.
- After `Update now`, PaperEngineer Shell waits for Windows Installer and says when the update is installed. Cancelling the administrator prompt is not reported as an error.
- `Check for updates` runs in the background, so File Explorer stays responsive while an update installs.

### Changed

- The prompt offers `Update now` and `Later`. `Skip this version` is gone, and a version skipped earlier is offered again.

### Notes

- The new version is used after File Explorer restarts: open Task Manager, select `Windows Explorer`, choose `Restart`. Signing out or restarting Windows also works.
- Until File Explorer restarts on 1.4.5, the running older version can still offer an update that is already installed. Restart File Explorer once after installing.
- Windows asks for administrator rights while the update installs.
- The add-in is unsigned. When Revit shows the security prompt, choose `Always Load`; `Load Once` asks again on every start.

### Installation

1. From 1.4.0 or later: accept the update prompt, or choose `Check for updates` in the right-click menu.
2. From an earlier version: download `PaperEngineerShell_1.4.5.msi`, close Revit, and run the installer as administrator. It replaces any earlier Revit Shell or PaperEngineer Shell version.
3. Right-click a supported Revit file to access the PaperEngineer Shell commands.

### Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Internet access to github.com for update checks
- Autodesk Revit installed for the versions you want to open (Detach and Create new local: Revit 2014–2027)
