## PaperEngineer Shell v1.3.0

Detach from central and Create new local now work in Revit 2014 through 2027.

### Changed

- The Open Helper add-in is installed for Revit 2014, 2015, 2016, 2017, 2018, 2019 and 2020, in addition to 2021–2027.
- The add-in for Revit 2014–2024 is now built against the Revit 2014 API, the oldest version it supports.

### Notes

- Revit Version Info and Open with exact Revit version work with any Revit version installed on the computer.
- Revit 2014–2020 and 2027 support has been checked against each version's API but not yet on a computer with those versions installed.
- Revit 2028 is not released yet. It will be added in a later version.
- The add-in is unsigned. When Revit shows the security prompt, choose `Always Load`; `Load Once` asks again on every start.

### Installation

1. Download `PaperEngineerShell_1.3.0.msi`.
2. Close all Windows Explorer windows and Revit.
3. Run the installer as administrator. It replaces any earlier Revit Shell or PaperEngineer Shell version.
4. Right-click a supported Revit file to access the PaperEngineer Shell commands.

### Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Autodesk Revit installed for the versions you want to open (Detach and Create new local: Revit 2014–2027)
