## PaperEngineer Shell v1.2.0

Revit Shell is now **PaperEngineer Shell**. The commands and how they work are unchanged.

### Changed

- New product name: PaperEngineer Shell. It shows in Apps & Features, the Start Menu and the Revit add-in list.
- New icon for the right-click menu and the installer. The old icon was the Autodesk logo and is no longer used.
- New install folder: `C:\Program Files\PaperEngineer\Shell`. The Revit add-in stays in `%ProgramData%\Autodesk\Revit\Addins\<year>`.

### Notes

- Installing 1.2.0 removes Revit Shell 1.0.0, 1.1.0 or 1.1.1 first, then installs PaperEngineer Shell. Your settings and models are not touched.
- The add-in is unsigned. When Revit shows the security prompt, choose `Always Load`; `Load Once` asks again on every start.
- Revit 2027 support is built against the Revit 2027 API but has not yet been tested on a Revit 2027 installation.

### Installation

1. Download `PaperEngineerShell_1.2.0.msi`.
2. Close all Windows Explorer windows and Revit.
3. Run the installer as administrator.
4. Right-click a supported Revit file to access the PaperEngineer Shell commands.

### Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Autodesk Revit installed for the versions you want to open (Detach and Create new local: Revit 2021–2027)
