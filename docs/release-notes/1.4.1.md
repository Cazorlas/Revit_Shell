## PaperEngineer Shell v1.4.1

Maintenance release. PaperEngineer Shell works the same as in 1.4.0.

### Changed

- No functional changes. This release lets 1.4.0 installations try the built-in updater: right-click a Revit file, choose `Check for updates`, then `Update now`.

### Notes

- Windows asks for administrator rights while the update installs, and may ask to close File Explorer.
- The add-in is unsigned. When Revit shows the security prompt, choose `Always Load`; `Load Once` asks again on every start.

### Installation

1. From 1.4.0: accept the update prompt, or choose `Check for updates` in the right-click menu.
2. From an earlier version: download `PaperEngineerShell_1.4.1.msi`, close all Windows Explorer windows and Revit, and run the installer as administrator. It replaces any earlier Revit Shell or PaperEngineer Shell version.
3. Right-click a supported Revit file to access the PaperEngineer Shell commands.

### Requirements

- Windows 10 or Windows 11
- .NET Framework 4.8
- Internet access to github.com for update checks
- Autodesk Revit installed for the versions you want to open (Detach and Create new local: Revit 2014–2027)
