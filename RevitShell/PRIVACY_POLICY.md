# Privacy Policy for Revit Shell

Effective date: June 30, 2026

Revit Shell respects user privacy. This application does not collect, store, transmit, sell, or share personal data.

## Local Processing

Revit Shell runs locally on the user's Windows machine. It reads selected Autodesk Revit file metadata only to detect the Revit version of supported files.

Supported file types:

- `.rvt`
- `.rfa`
- `.rft`
- `.rte`

Revit Shell also reads the local Windows registry only to find installed Autodesk Revit applications so it can open a selected file with the matching Revit version.

## No Data Collection

Revit Shell does not use:

- Analytics
- Telemetry
- Advertising SDKs
- Account login
- Cloud services
- Third-party tracking

No Revit project, family, template, or library files are uploaded or transmitted by Revit Shell.

## No Personal Data Storage

Because Revit Shell does not collect personal data, it does not retain personal data and has no personal data to delete.

## File Access

Revit Shell accesses only the files selected by the user in Windows Explorer. File access is used for local version detection and local launch behavior.

## Changes to This Policy

This policy may be updated when Revit Shell changes how it handles data. Any future update will be reflected in this document.

## Contact

For privacy questions about Revit Shell, contact the publisher of the application.
